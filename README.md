# homebrew-tap

Personal [Homebrew](https://brew.sh) tap for [G-Schumacher44](https://github.com/G-Schumacher44)'s tools.

## Usage

```bash
brew tap g-schumacher44/tap
brew install review-pantheon
```

| Formula | What it is |
|---|---|
| [`review-pantheon`](Formula/review-pantheon.rb) | Fail-closed AI review gate — hunter/verifier twins (Artemis/Apollo) on every PR, philosopher counsel (Socrates/Diogenes/Plato) in design. Installs the `pantheon` CLI. [Repo](https://github.com/G-Schumacher44/review-pantheon) · also on [PyPI](https://pypi.org/project/review-pantheon/) and the [GitHub Marketplace](https://github.com/marketplace/actions/review-pantheon-gate). |

Formulas here track tagged releases of their upstream repos; versions are pinned to release artifacts with checksums.
